# Career Asset Manager (CAM)

You are a senior software architect, backend engineer, DevOps engineer, and UI/UX designer.

Your task is to build a **production-quality web application**, not a student CRUD project.

The project should follow clean architecture, scalable design, proper coding standards, and be modular.

---

# Project Name

Career Asset Manager (CAM)

---

# Project Vision

Career Asset Manager is a personal career management platform that helps software engineers organize, optimize, and manage every asset related to their professional career.

Instead of storing resumes in random folders, the platform becomes the single source of truth for:

* Resume versions
* Cover letters
* Company profiles
* Job descriptions
* Skill gap analysis
* ATS optimization
* Career documents
* Application tracking

The system should feel like a professional SaaS product.

---

# Primary Goal

Help users quickly prepare the best application for any company by intelligently managing resumes and comparing them against company requirements.
